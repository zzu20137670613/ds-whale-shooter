# 深海回响 · 枪火柔情 — v1.6.5（versionCode 15，安卓测试包）

修「打死卷轴关的 boss 必卡死」。这一版的重点不是改玩法，而是**让一帧出错不再能把整局冻死**，
并且把出错的那句话直接摆到屏幕上。

## 这一版改了什么

```
· 卡死的原因：Phaser 4 的主循环是「先跑回调、再预约下一帧」——

      this.callback(time);                    ← 这里一抛，下一行就不执行了
      if (this.isRunning) requestAnimationFrame(step);

  所以只要某一帧里任何一个回调抛出异常（计时器回调、补间回调、物理或渲染），
  RAF 链就永久断掉：画布停在最后一帧，而 React/DOM 完全正常 ——
  这正是「界面不动，摇杆和背包还能点」。

· 修法：在交给 RAF 的那个回调外面包一层 try/catch。最坏结果降级成「这一帧白跑」，
  下一帧照常，游戏继续。场景 update 原本就有一层（1.4.0 修的「一帧坏掉不再毁一局」），
  但计时器、补间、物理、渲染都不经过它，这次补上了地基那一层。

· 掉战利品这一环单独加了兜底（上下文名 `monster:died`）。它由死亡动画的计时器触发，
  正好在原来那层保护之外。

· 新增屏幕上的红色报错条：出错的上下文和消息停在那里，点「知道了」才消失。
  下次再出问题，把这条截图发我，比「又卡了」有用得多。
```
