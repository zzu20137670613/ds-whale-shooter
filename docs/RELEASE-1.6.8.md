## 改了什么

```
· 颜色：深金 0xB45309 → 亮金 0xFFD24A。
  主人 2026-11-15：`明明你之前给我的图是金色的，实际怎么变成了橙色，这色差有点大啊`。
  原因：光柱是用 `setTint` 乘在近白贴图上（out = tex × tint / 255），0xB45309 本身偏橙褐，
  乘上去就是橙。亮金（红 255 / 绿 210 / 蓝 74）乘出来核心发白、边缘偏金，才是金色。
  地面光斑同步换成 0xFFC247。

· 宽度：柱身 ×1.5（115px → 173px），高度不变（259px，主人明确说高度不用调）。
  地面光斑跟着从 96 宽放到 144，否则柱身比底座宽，看着头重脚轻。
```

紫（白龙獠牙）和留给未至之境的白色没动。
