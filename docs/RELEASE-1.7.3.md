# 深海回响 · 枪火柔情 — v1.7.3（双端）

这一版只有一个主题：**她会说话了**。

## 1. 鲸鱼娘开始说话

关卡里每隔 **60～90 秒**，鲸鱼娘会忽然说一句。只在她出场时说话，亭台选人界面不吵。

台词池 **24 条**，四个方向：

```
桌宠        6 条   反向安利桌面端——她去陪你，我在打枪
galgame     8 条   安利《深海回响·鲸鲸》：双端、直连 API、可调最大上下文
枪火柔情    6 条   开源、双端、release 有成品包
元台词      4 条   自嘲和闲聊
```

抽法是**洗牌 + 记忆窗口**：

```
一轮之内不重复（抽完再洗）
最近 5 句不会再被抽到 —— 包括刚洗完牌恰好排最前那句
```

所以同一段故事里不会连续听到同一句，也不会出现“三分钟只说那两句”的情况。

## 2. 所有台词统一进提示框

以前有三条不同的通道：王座彩蛋、果汁彩蛋走头顶，提示走顶部框，这次新加的台词又在头顶——**位置和样式都不一样**。

现在统一成一条：**全部走顶部那条琥珀色描边的框**，字号、位置、样式都一样。头顶那条通道整块删掉了。

配套的一处改动：**提示停留时间按字数算**（2.8～6 秒）。原来固定 2.8 秒，长的台词（最长 46 字）还没读完就没了。
