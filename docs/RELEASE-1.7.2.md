1.7.1 之后的改动：两处数值调整、一个新道具、一处彩蛋、两处字号。

## 1. 数值（双端）

**金钱**（按数据总表 E 列）

**生命碎片与灵力碎片对调**（实测后期灵力更吃紧）

```
无人机 / 超级无人机   生命 30% → 10%，灵力 10% → 30%
枪手 / 潜行者        生命 50% → 20%，灵力 20% → 50%
守夜人 / 狙击手      生命 30% → 20%，灵力 20% → 30%
```

再往下，**奔波儿灞、Bunny、猫猫、看守者四只不再掉生命碎片，改掉灵力碎片**（概率档位照搬）。
现在没有任何怪物会掉生命碎片 —— 补血只靠商店和捡掉落。

## 3. 彩蛋：礁石上那杯深海特饮

海滩假日出生点旁，一杯深海特饮落在画出来的礁石上。它本来是"开场礼物"换过之后没人删的遗留，
坐标又恰好压在石头上 —— 看着像刻意埋的彩蛋，就留着了。

捡起来会说一句：**「礁石上有杯深海特饮……是谁放在这儿的？」**
（这句只在这张图说；同样的深海特饮从怪身上掉出来时不弹。）
