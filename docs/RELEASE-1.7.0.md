## 2. 手机端漫画「跳过」挪到右下角

TapTap 的悬浮退出按钮在右上角，两个挤在一起互相影响。漫画是全屏覆盖层，右下角本来没有摇杆
和开火键。**只改手机端**，PC 仍在右上角。

## 3. 手机端存档读档：至少一行完整可见

手机屏高比平板/模拟器低，原来一行卡片的按钮会被切掉。现在缩略图 84 → 48 px、卡片内边距和
间距一起收，网格限高按视口算（`calc(100vh - 7.5rem)`），面板本身也收紧。桌面尺寸一个像素没动。

## 4. 结局视频「跳过」修好了（双端）

真实现场：

```
TypeError: Cannot read properties of null (reading 'queueOp')
    at ScenePlugin.resume (phaser.js)
    at story-video.tsx  ← 跳过时恢复场景
```

片子在播的时候关卡已经被整个换掉（读档直打第四关最容易撞上）：`scene.scene` 还在，
`scene.sys` 已是 null，`resume()` 直接抛。旧代码先在 `resume()` 这步抛出来，`setSrc(null)`
永远执行不到，而「已收尾」标志已经置真 —— 之后每次点跳过都被挡回去，表现就是
「视频在放、按钮在、点了没反应」。

修法：

```
· setSrc(null) 提到第一句 —— 画面一定撤得掉
· 场景只在 sys 非空时才 pause / resume（被换掉的关卡静默跳过）
· 恢复音乐、发 DONE 各自兜底
· 另加 Esc 也能跳过
```
