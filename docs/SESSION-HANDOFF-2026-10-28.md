## 二、这一场定下的设计（写死了，别改）

1. **磁吸（自动索敌）永久停用**。键鼠=鼠标指哪打哪；方向键/手柄/触屏=8 方向。**没有第三种模式。**
2. **闪避朝移动方向**；站着不动时朝躯干朝向。
3. **8 方向模式下躯干朝瞄准方向**；触屏瞄准=移动方向。
4. **Boss 伤害按"满级鲸鲸 + 满级桌宠"校准**，主人原话：「没把桌宠练满，这场仗会非常痛。是我想要的。」
5. **Boss 数值**（阶段 1）：HP 4000 / 护甲 20 / 移速 7 / 三连炮 130 / 近战 140 / 天谴 180。
6. **存档分两套键**：自动存档 `11th_forest_save_v2`，槽位 `11th_forest_slot_1..6` + `11th_forest_quicksave`。**绝不共用一个 key。**
7. **自动快存的时机 = 离开到达用的那个传送阵的半径**（不是刚到的时候），否则读档会立刻又被传走。
8. **Gemini = Seed 的数值 + 九命猫**，护盾**先过护甲**再吃伤害，碎盾当刻开始冷却，溢出伤害照进血。
