# 深海回响 · 枪火柔情 — v1.6.9（双端）

爆率重调 + 两把枪的射速重调。PC 与手机同版本号、同一份数据。

## 这一版改了什么

### 爆率（「怪物」sheet I 列，2026-11-15 主人改）

```
· 星空潜行者   hp-shard 100% → 30%
· 龙城守卫     hp-shard 100% → 40%
· 云海德鲁伊   hp-shard 100% → 40%
· 星海狙击手   hp-shard 100% → 30%
· 钢铁典狱长   hp-shard 100% → 50%
· 奔波儿灞     hp-shard 100% → 50%
· 藤壶炮手     barnacle 100% → 80%
· 藤壶寄生者   barnacle 100% → 80%
```

只改了「掉至少一个」那一档（`chance`）；掉 2 / 3 个的档位（`chance2` / `chance3`）没动。

### 射速

```
· 突击步枪    cooldownMs 200 → 125   每秒 8 发（原来 5 发）
· 白龙獠牙    cooldownMs 100 → 167   每秒 6 发 × 2 弹丸（原来 10 发 × 2）
```

对调之后理论输出：突击步枪 8 × 30 = **240/秒**，白龙獠牙 6 × 2 × 25 = **300/秒** ——
剧情枪仍然略强于商店枪，但差距从 3.3 倍收到 1.25 倍。

### 手机端顺带带上

```
· 1.6.6  修掉词元盾光柱里的 `Phaser is not defined`（没 import 引擎）
· 1.6.7  修掉换关之后光柱复用死帧导致的 `sourceSize of null`
· 1.6.5  主循环兜底 + 屏幕上的红色报错条（一帧出错不再冻死整局）
· 1.6.8  光柱改亮金 0xFFD24A、柱身加宽 1.5 倍
```
