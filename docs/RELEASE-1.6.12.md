# 深海回响 · 枪火柔情 — v1.6.12（双端）

三件事：boss 关的饭盆提示、饭盆在背包里的样子、海底特饮的专属图标。外加一条把整个手机
崩溃排查串起来的结构性修复。

## 1. 踩饭盆没提示（根因）

不是饭盆的问题，是**整帧被前一个异常吞掉了**。

场景每帧按顺序跑十几个子系统，原来它们共用一个大 `try`。11-15 那个 `BossArenaLoop.movePlayer`
的 `setPosition of undefined`（见 v1.6.11）抛在很靠前的位置，而「踩饭盆判定」排在它后面 ——
于是只要 boss 走位那一步在抛，饭盆的判定这一帧就根本不会执行：道具是之前进包的，提示永远不会来。

改法：把那个大 `try` 拆成**每个子系统各自兜底**（`guard('drops', …)`、`guard('interactables', …)`
……）。一处坏掉只坏它自己，异常照样进崩溃日志。

顺带修掉的还有同一批「排队饿死」的子系统：掉落物更新、触发器、传送阵、材质、存档时钟。

## 2. 饭盆（白米饭）

```
· 背包里的名字：deepseek的大白饭饭盆 → 白米饭
· 图标底色：0xCFD6DD（浅银灰，在暗底背包里是一块亮斑）→ 0x1B2230（深蓝灰，和面板同调）
· 点击时的提示：`这个不能在这里使用`
              → `这个是【未至之境】中的关键道具，现在不能使用`
```

第三条做成了**物品自带文案**（drop YAML 里新增可选的 `unusableNotice` / `unusableNoticeZh`），
不是把通用那句改掉 —— 别的材料点了还是原来那句。

## 3. 海底特饮有自己的图了

之前它一直是 `drops.png` 里生命碎片那一格（YAML 里写着 PLACEHOLDER），所以背包里两个东西长得一样、
只是底色不同。现在有专属 64×64：深海底色的蓝、两块冰、一根玫红吸管，口径和饭盆图标一致
（64 色阶压到 16、1px 深色描边、透明背景）。
