# 深海回响 · 枪火柔情 — v1.7.1（双端）

1.7.0 之后的小修：三处手感与显示，一处数值。

## 1. 掉率下调（双端）

生命碎片在四只怪身上都调低了，其余掉落没动：

```
奔波儿灞     50% → 30%
超级无人机   40% → 30%
守夜人       40% → 30%
看守者       50% → 30%
```

只动「至少掉 1 个」那一档；「掉 2 个 / 掉 3 个」的多掉档位保持原样。

## 2. boss 链的「用时」改成四关合计（双端）

以前一个大关是一张超大图，末关结算读到的就是整关用时。后来超大图拆成 2×2 的四张，
结算仍然只在第四张触发 —— 于是那行「用时」只剩最后一张的时长，跑了一小时的玩家看到「06:12」。

现在每关的首领倒下时各记一笔（写进存档，重开也留着），末关结算把同一章的四关加起来。
读档直打末关也能算，只合计已有的那几张。

## 3. 手机端赞赏页面等比缩小

面板按 67.5rem 画，手机横向时高度不够，底下的按钮会被切掉。现在整块按实际尺寸算一个 ≤1
的比例缩放 —— 版式原样，不逐个改字号。桌面上算出来是 1，等于没动。

## 4. 图鉴里词元盾的描述（双端）

「词元盾 +1 级（最多 5 级）」→「最多 10 级」。这句话现在读的是常量，以后上限再变，
图鉴自己会跟上，不会再落后一个版本。
