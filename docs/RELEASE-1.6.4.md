# 深海回响 · 枪火柔情 — v1.6.4（versionCode 14，安卓测试包）

手机测试版。1.6.3 之后的两笔改动：饭盆图标 + 全怪物爆率下调。
（1.6.3 已经包含：提示字号加大、词元盾光柱换成 48 帧序列帧、光柱按物品上色、
饭盆 spec 预取、饭盆每次踏入都说台词、boss 关不再抹掉武器等级。）

## 这一版改了什么

```
· 道具「deepseek的大白饭饭盆」有图标了：不锈钢饭盆 + 一盆白米饭 + 鲸鱼贴纸，
  抠掉粉背景、压成 64×64 像素风，加 1px 深色描边。背包里不再是灰色方块。

· 全怪物爆率下调（按 2026-11-14 设计表 I 列）：
  · 星空潜行者 / 龙城守卫：灵力碎片 40% → 10%，弹药箱 30% → 5%，过载核心 15% → 1%
  · 云海德鲁伊：灵力碎片 40% → 20%，弹药箱 30% → 10%，过载核心 15% → 1%
  · 星海狙击手：灵力碎片 50% → 20%，弹药箱 20% → 10%
  · 钢铁典狱长：过载核心 40% → 20%，弹药箱 30% → 10%，深海鲜饮 15% → 5%
  · 奔波儿灞：新增生命碎片 100%，弹药箱 60% → 20%，过载核心 40% → 10%，深海鲜饮 15% → 5%
  · 只改了「掉至少一个」的主概率，掉 2 / 3 个的档位（chance2 / chance3）未动。
```
